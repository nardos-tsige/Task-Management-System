# Task Management System

A premium, responsive task manager built with pure Vanilla JavaScript, HTML, and CSS. 

## Features
- Create, edit, delete, and drag-to-reorder tasks
- Local storage persistence for tasks and theme
- Filter, search, and live statistics
- Dark and light mode
- Custom inline SVG illustrations and smooth animations
- Fully accessible and keyboard-friendly

## Run Locally
Open `index.html` in your browser, or use VS Code Live Server.

## Tech Stack
HTML5, CSS3 (Custom Properties, Flexbox/Grid), JavaScript (ES6+).
